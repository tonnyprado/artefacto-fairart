SECCIÓN 1 · REGLA DE NEGOCIO
--------------------------------------------------------

INPUT DEL ARTISTA (único campo editable):
  "Tu precio (MXN)" = lo que el artista quiere ganar por la obra.

CONSTANTES (en configuración, NO hardcodeadas):
  PORCENTAJE_ARTISTA  = 0.75    (75%)
  PORCENTAJE_COMISION = 0.25    (25%)
  MULTIPLO_REDONDEO   = 500     (cubre también los miles)

CÁLCULOS:
  ganancia        = input                        (intacta siempre)
  precio_publico  = input / 0.75
  comision        = precio_publico - input       (= 25%)
  precio_sugerido = techo(precio_publico / 500) * 500
                    → SIEMPRE hacia arriba (Math.ceil).
                    Nunca redondear hacia abajo ni "al más
                    cercano": el sugerido jamás puede quedar
                    por debajo del precio al público.

El precio sugerido es SOLO una referencia visual. No modifica
la comisión ni la ganancia. El diferencial entre precio al
público y precio sugerido NO se muestra ni se guarda como
ajuste — los precios definitivos se pactan en la hoja de
consigna al ser seleccionado.

// ---------- lógica (compartida frontend/backend) ----------

const CONFIG_PRECIO = {
  porcentajeArtista: 0.75,
  multiploRedondeo: 500,
};

/**
 * @param {number} input - "Tu precio": ganancia deseada (MXN, > 0)
 * @returns {{ganancia, comision, precioPublico, precioSugerido}}
 * @throws {Error} si el input no es un número positivo
 */
function calcularPrecio(input, config = CONFIG_PRECIO) {
  if (typeof input !== 'number' || !isFinite(input) || input <= 0) {
    throw new Error('El precio debe ser un número mayor a cero');
  }
  const precioPublico = input / config.porcentajeArtista;
  const comision = precioPublico - input;
  const m = config.multiploRedondeo;
  const precioSugerido = Math.ceil(precioPublico / m) * m;

  return {
    ganancia: centavos(input),
    comision: centavos(comision),
    precioPublico: centavos(precioPublico),
    precioSugerido: centavos(precioSugerido),
  };
}

function centavos(n) {
  return Math.round(n * 100) / 100;
}

// ---------- ejemplo de wiring en la UI ----------

/*
HTML esperado (ids):
  #precio        input numérico
  #gan #com #pub #sug   celdas de resultado
  #info          el círculo (i)
  #tip           el tooltip (display:none por default)
  #err           mensaje de validación
*/

const fmt = n => '$' + n.toLocaleString('es-MX',
  {minimumFractionDigits: 2, maximumFractionDigits: 2});

function render() {
  const el = id => document.getElementById(id);
  const v = parseFloat(el('precio').value);
  try {
    const r = calcularPrecio(v);
    el('err').style.display = 'none';
    el('gan').textContent = fmt(r.ganancia);
    el('com').textContent = fmt(r.comision);
    el('pub').textContent = fmt(r.precioPublico);
    el('sug').textContent = fmt(r.precioSugerido);
  } catch (e) {
    el('err').style.display = 'block';
    ['gan','com','pub','sug'].forEach(id =>
      el(id).textContent = '—');
  }
}
document.getElementById('precio')
  .addEventListener('input', render);
render();

// ---------- tooltip: hover (desktop) + tap/focus (móvil) ----------

const info = document.getElementById('info');
const tip = document.getElementById('tip');
// El elemento #info debe tener tabindex="0" en el HTML
info.addEventListener('mouseenter', () => tip.style.display = 'block');
info.addEventListener('mouseleave', () => tip.style.display = 'none');
info.addEventListener('focus',      () => tip.style.display = 'block');
info.addEventListener('blur',       () => tip.style.display = 'none');
info.addEventListener('click', (e) => {
  e.stopPropagation();
  tip.style.display =
    tip.style.display === 'block' ? 'none' : 'block';
});

SECCIÓN 4 · NOTAS DE IMPLEMENTACIÓN
--------------------------------------------------------

1. BACKEND OBLIGATORIO. calcularPrecio() debe ejecutarse
   también en el servidor al guardar cada obra. El navegador
   solo muestra; el servidor valida y persiste. Si difieren,
   manda el servidor.

2. QUÉ SE GUARDA POR OBRA (los 4 campos):
   ganancia, comision, precioPublico, precioSugerido.
   Si el backend maneja dinero, preferir centavos enteros
   (pesos × 100) para evitar errores de punto flotante.

3. PRECISIÓN. Calcular con precisión completa y redondear a
   centavos solo al final (función centavos). No encadenar
   valores ya redondeados.

4. VALIDACIÓN DE INPUT: solo números > 0; rechazar 0,
   negativos y texto. Ganancia mínima capturable: [PENDIENTE
   — Benito define, sugerido $500 MXN].

5. TESTS (múltiplo 500, siempre hacia arriba):
   input 10,000 → ganancia 10,000 · comisión 2,500
                  público 13,333.33 · sugerido 13,500
   input 7,500  → ganancia 7,500 · comisión 2,500
                  público 10,000 · sugerido 10,000
                  (ya es múltiplo: no se mueve)
   input 400    → ganancia 400 · comisión 133.33
                  público 533.33 · sugerido 1,000... NO:
                  ceil(533.33/500)*500 = 1,000 ✗ → revisar:
                  533.33/500 = 1.0667 → ceil = 2 → 1,000 ✓
                  (correcto: sugerido 1,000)
   input 300    → público 400 → sugerido 500
   Invariantes: ganancia + comision == precioPublico (±0.01)
                precioSugerido >= precioPublico
                precioSugerido % 500 == 0

6. TEXTOS UI — copiar EXACTO (etiquetas, tooltip y
   asteriscos) de la Sección 2. No parafrasear.
